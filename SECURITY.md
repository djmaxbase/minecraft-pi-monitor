# Beveiligingsmeldingen

Plaats kwetsbaarheden of credentials niet in openbare issues. Gebruik GitHub private vulnerability reporting op de Security-tab wanneer beschikbaar. Als deze functie niet beschikbaar is, maak alleen een issue met een verzoek om een privékanaal, zonder exploitatiedetails. Draai de app op vertrouwd LAN of achter VPN/HTTPS. Behandel ingelezen servertekst en chat als onbetrouwbaar. De ingestiesleutel geeft uitsluitend schrijftoegang tot chat.
