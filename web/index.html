Bestaand log importeren
Kies een Minecraft .log/.txt-bestand. Alleen herkenbare chatregels worden geïmporteerd; het oorspronkelijke tijdstip blijft in de ruwe regel bewaard. Schakel Chatlog eerst in bij Instellingen.




Gemonitorde server
Eén actief profiel. Een ander adres krijgt een eigen historie; eerdere profielen blijven bewaard in de database.
GitHub Releases
Updates worden gecontroleerd met de ingebouwde publieke sleutel. Installeren gebeurt alleen op jouw verzoek.


Telefoonmeldingen
Installeer de ntfy-app op je telefoon en abonneer je op het topic hieronder. Gebruik bij een eigen ntfy-server hetzelfde serveradres in de app.
Een willekeurig topic is standaard niet afgeschermd: wie de naam kent kan meelezen of publiceren. Gebruik topic-toegangsbeheer voor privé meldingen.
 


Updates via dit dashboard
Offline herstel: kies een vertrouwde Minecraft Pi Monitor release-ZIP. De app controleert het pakket, maakt een databasebackup, installeert en herstart. Je instellingen en historie blijven behouden.
Installeer alleen een vertrouwd pakket: een update bevat uitvoerbare code. De bestandscontrole controleert integriteit, geen uitgevershandtekening. Bij een mislukte start zet de supervisor de vorige code terug.


Chatkoppeling
Start chat-relay.py op de Minecraft-server of op je Minecraft-pc. De volledige stappen staan in de handleiding.
Chatsleutel tonen
De sleutel mag alleen chat toevoegen en geeft geen toegang tot het dashboard. Gebruik je eigen netwerk of VPN voor de verbinding.
